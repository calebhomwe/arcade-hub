# Assets used by the kids' games (Whack-a-Mole, Memory Match, Bubble Pop, Simon Says, Word Scramble)
- fx/*.webp: Microsoft Fluent Emoji 3D, MIT licence (FLUENT-LICENSE.txt), resized to 192px.
